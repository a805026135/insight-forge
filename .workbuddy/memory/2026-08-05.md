## InsightForge（智析）多智能体数据分析报告平台 — 设计探讨（brainstorm 阶段）
- 目标：面试项目，但要求真实完整、可落地上线、可量化评估（非纯 demo）。
- Agent 方向：LLM 智能体（AI Agent），非 Java instrumentation agent。
- 场景：多智能体数据分析与报告平台（避开了烂大街的企业知识库 RAG 问答）。
- Agent 实现：自研调度编排 + Spring AI 接模型（混合）。
- 模型：DeepSeek（成本/中文/推理均衡）。
- 数据接入：文件为主（CSV/Excel/Parquet）+ 可选 JDBC。
- 前端：React 18 + TS + Vite + Ant Design + ECharts（独立前端 + 后端 REST）。
- 技术栈按用户要求叠加企业级/黑马点评范式：MySQL8、Redis7+Redisson、Kafka、Caffeine+Redis 多级缓存、Milvus 向量库、JWT、Redis+Lua 限流、JMeter 压测、Nginx、Docker Compose、GitHub Actions、Actuator+Prometheus+Grafana。
- 用户强调：技术栈要足够、考虑多并发与部署、数据库/向量库用企业级、结合黑马点评确保完整性。
- 进度：已完成 brainstorm 提问 + §1~§1.5 设计；正在细化 §3 Agent Core / §4 数据接入+沙箱+状态机；待补 §5 评估闭环、§6 项目结构/里程碑；之后落盘 spec 文档到 docs/plans/。
