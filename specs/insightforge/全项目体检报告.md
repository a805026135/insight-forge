## 四、诚实边界桩清单（设计即桩，非 bug）

全仓 31 个文件含「桩/stub/本地」标记，核心是下面 7 处**有意为之的本地实现**——项目铁律要求「实跑与未实跑分清」，这些在沙箱用确定性桩保证逻辑可验证，生产需替换：

| 桩类 | 位置 | 当前实现 | 生产应换 | 影响面 |
|---|---|---|---|---|
| `LocalLockService` | rule-engine | 本地 `ReentrantLock` | Redisson 分布式锁 | 护栏指令执行的互斥（与秒杀同把锁的语义未真验证） |
| `InMemoryPolicySource` | rule-engine | 内存 Map 缓存 DSL | Redis/DB 持久化策略 | 策略版本分发 |
| `LocalDeterministicModelClient` | agent-core | 离线确定性桩 | DeepSeek（Spring AI 接） | Agent 离线规划（热路径零 LLM，不进热路径） |
| `InMemoryBusinessMetricsSource` | evaluation | 内存种子（人工82%/28% vs AI95%/36%） | 真实业务表聚合 | A/B 评估数据源 |
| `InMemorySystemRunMetricsSource` | evaluation | 内存种子 | 真实运行日志聚合 | 正确失败率/延迟数据源 |
| `web_search` | agent-core | 本地桩 | 真实检索工具 | Agent 取数工具之一 |
| `Milvus` 长期记忆 | agent-core | 显式桩（未接入） | Milvus 向量库 | 三层记忆中的长期记忆/语义缓存 |

> 这些**不是缺陷**，是「先把控制面/数据面分离的逻辑跑通、再换真中间件」的分阶段策略。评估闭环的门槛逻辑、A/B 判定、失败样本重放都是**确定性可验证**的，不依赖这些桩的真假。

## 五、技术债与可优化清单（M7+ 方向）

按「是否阻断上线」分两档：

### 5.1 上线前建议替换（诚实边界 → 真实）

1. **真实分布式锁**：`LocalLockService` → Redisson。项目灵魂是「防超卖靠锁 + 原子条件更新」，但热路径锁仍用本地桩，跨进程/多实例下不保证互斥。**这是当前最大的诚实缺口**。
2. **真实策略源**：`InMemoryPolicySource` → Redis/DB，策略版本化分发（已有 `GuardrailPolicyRepository` 版本化骨架）。
3. **评估数据源接真表**：两个 `InMemory*Source` → 真实业务/运行日志聚合，让 A/B 与正确失败率来自生产数据。
4. **Milvus 接入**：长期记忆/语义缓存（控制面规划时可复用历史决策）。

### 5.2 功能完整性（scope 红线 M7+）

5. **支付链路**：Phase 6 状态机已预留 `PAY` 状态与迁移矩阵，但无支付回调/超时关单。
6. **Kafka 消费侧**：`sales.tick` 生产侧已设计，rule-engine worker 消费侧需在本机实跑指南档位 C 验证真正在跑。
7. **Redis 多级缓存生产验证**：Phase 5 `MultiLevelCache` 已实跑（逻辑层），但生产 Redis 配置与预热需本机验证。

### 5.3 工程增强（非阻塞）

8. **测试覆盖率门禁**：引入 JaCoCo，设行覆盖/分支覆盖阈值（当前 83 测试全绿但无覆盖率约束）。
9. **代码风格/静态检查**：Spotless + Checkstyle，统一格式（当前靠人工约定）。
10. **API 契约测试**：对 `/api/seckill`、`/api/dashboard/*` 加契约测试，防接口回归。
11. **依赖体检自动化**：`mvn dependency:analyze` 定期查未使用/未声明依赖（当前手动盘点干净）。

## 附 A：沙箱构建命令（JDK21 跨盘 fix）

```bash
# Git Bash 下 MAVEN_HOME 未被识别，用 classworlds Launcher 直拉 + Windows 风格路径
MVN_WIN="D:/devtools/maven/apache-maven-3.9.9"
export JAVA_TOOL_OPTIONS="-Djava.io.tmpdir=D:/Java/tmp"   # 与工程同盘，避 JDK21 Surefire 跨盘崩溃
cd D:/Java/insightforge
java -classpath "$MVN_WIN/boot/plexus-classworlds-2.8.0.jar" \
  "-Dclassworlds.conf=$MVN_WIN/bin/m2.conf" \
  "-Dmaven.home=$MVN_WIN" \
  "-Dmaven.multiModuleProjectDirectory=D:/Java/insightforge" \
  org.codehaus.plexus.classworlds.launcher.Launcher -B clean package
# 父 POM 已含 surefire argLine=-Djdk.net.URLClassPath.disableClassPathURLCheck=true 兜底
```
