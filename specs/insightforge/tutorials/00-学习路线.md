# InsightForge 学习路线（主线必学 × 选做进阶）

> 本文是教程的「地图」。先花 1 分钟读它，能少走很多弯路。

## 一句话定位

本项目的**面试核心**只有两条线：

1. **用户侧 · 高并发秒杀**（Phase 0–6）：Redis+Lua 原子扣减、Redisson 分布式锁、Kafka 削峰、多级缓存、限流、状态机、对账。**这是命门，必学。**
2. **系统侧 · 控制面/数据面分离的 Agent 护栏**（Phase 7–9 精简主线）：LLM **离线**生成护栏 DSL → Drools **在线**确定性执行 → **零 LLM 进热路径**。**这是差异化卖点，必学其故事线。**

其余围绕 Agent 的「框架基建」（多智能体编制、运行时观测、评估框架、大屏……）是**加分项**，学习成本高、对讲清核心卖点非必需——统一收进后面的 **选做进阶** 章节，按需取用，**跳过不影响主线理解**。

## 主线必学（建议按顺序）

| 章节 | 讲什么 | 为什么必学 |
| --- | --- | --- |
| Phase 0–6 | 秒杀高并发全栈 | 面试最高频，命门 |
| Phase 7（精简） | 为什么需要 Agent 离线生成护栏 DSL；一个最小 Planner 调模型产出 `GuardrailPolicy`；`DslCompiler` 校验（Fail-Close） | 控制面灵魂 |
| Phase 8（精简） | DSL 版本化入库 + 缓存；产出可上线 DSL | 数据面的原料 |
| Phase 9（精简） | Drools 在线执行 DSL（**零 LLM 热路径**）；`ControlInstructionExecutor` 输出指令 | 数据面灵魂 |
| Phase 10 / 11 | 概念了解：可观测、评估闭环（golden 回归 + 正确失败率） | 知道有即可 |

**主线目标**：能流利讲清楚——*「用户抢购走 Redis Lua 原子扣减；Agent 离线出护栏 DSL、在线由 Drools 确定性执行、绝不在热路径调 LLM；两者通过同一份 Redis 库存键相遇。」*

## 常见疑问

**Q：我时间只够看主线，能应付面试吗？**
能。主线讲清「高并发秒杀 + 控制面/数据面分离」两条线，已经是强差异化项目。选做是锦上添花。

**Q：选做章节和 Phase 7–11 内容重复吗？**
不重复。Phase 7–11 是「按构建顺序的完整记录」，选做章是「按主题抽取的深度参考」。读 Phase 7–11 时若觉得某块太重，看章首的「⚠️ 选做」标注，按需跳到对应选做章，或跳过。

**Q：为什么这些被标成选做？**
因为它们对「讲清核心卖点」的边际增益小、学习成本高（详见各章「为什么是选做」）。标选做是为了**降低学习大山**，不是否定其价值——想深入随时可读。
