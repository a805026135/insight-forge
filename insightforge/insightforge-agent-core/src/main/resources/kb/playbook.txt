平台运营手册（商家必读）

一、秒杀活动规则
1. 秒杀活动商品必须真实在售，售价必须高于成本价，秒杀价建议为市场价的 5~8 折。
2. 每个秒杀 SKU 有独立的活动库存池，活动期间按秒杀价扣减活动库存，不占用普通库存。
3. 单用户对同一秒杀 SKU 限购 1 件，系统通过幂等键防止重复提交。
4. 秒杀活动开始后不得修改活动价与库存总量；确需调整时须先暂停活动。
5. 活动结束后，未售罄的剩余活动库存会回滚到普通库存。

二、上下架规范
1. 商品必须先通过平台审核（资质与图片完整）才能上架。
2. 缺货或无法履约的商品应主动下架，避免产生超卖与客诉。
3. 下架操作不影响已支付订单，商家仍须按时发货。
4. 参与秒杀活动的商品在活动期间不建议下架，如必须下架应先暂停活动。

三、定价与调价规范
1. 市场价不得低于成本价，毛利低于 5% 的调价会被平台风控拦截。
2. 调价需说明理由；大促期间价格保护窗口为活动前后各 24 小时。
3. 建议热销 SKU 保持现价并观察 2 小时，库存消耗率超过 40% 且毛利充足时可小幅下调 3%~5% 冲量。
4. 所有调价与库存调整动作都会写入审计日志，作为对账与复盘依据。

四、库存管理
1. 商家应维护每件商品的安全库存线，建议不低于近 7 日日均销量的 2 倍。
2. 库存低于安全线时应优先补货；单 SKU 剩余库存低于 15% 时触发补货建议。
3. 秒杀活动前请确认活动库存充足，避免活动开始后临时改库存。
4. 每次库存调整都会校验非负，防止误操作导致负数库存。

五、发货与售后
1. 订单支付后 48 小时内必须发货，超时会触发平台催发与赔付。
2. 发货时填写真实物流单号；虚假发货将被平台处罚。
3. 支持 7 天无理由退货，食品与定制类商品除外。
4. 售后工单应在 24 小时内响应，退款在确认收货后 48 小时内原路退回。

六、AI 运营助手使用规范
1. 商家 AI 助手只读经营数据并给出建议，所有写入操作（加库存、上下架、调价）必须先由商家确认。
2. 建议优先使用助手查询：库存消耗、销售分析、定价建议、文案生成。
3. 助手生成的动作建议在执行前都会展示给商家，由商家点击确认后才会生效。
4. 知识库会沉淀平台规则、商家商品资料与历史决策，帮助助手给出更贴近本店情况的回答。
